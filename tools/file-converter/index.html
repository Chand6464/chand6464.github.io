Supported conversions

Images: AVIF, BMP, GIF, ICO, JPG, PNG, PSD, TIFF, and WEBP can be converted between each other. SVG converts to PNG, JPG, or WEBP; image files can also be exported as EPS or PS. EPS/PS input needs Ghostscript, which is not included. ODD is not a recognized raster image format; confirm the actual file type before converting it. Text: CSV ↔ JSON, HTML/Markdown to plain text or HTML, and JSON to plain text. Other file types are not converted by simply renaming them.
